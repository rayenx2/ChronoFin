Prediction

Next-day XGBoost Forecast

Trains on 2 years of live OHLCV + 16 technical indicators per symbol. Returns predicted price with a 95% confidence interval. Yahoo Finance shows history, this shows where the price might go tomorrow.

Sentiment

News Sentiment Signal

Fetches live headlines from Yahoo Finance news feed and scores each one with VADER (-1.0 to +1.0). Aggregates into a daily Bullish/Bearish/Neutral signal. Price models miss this, sentiment catches it.

Backtesting

Honest Walk-Forward Backtest

Trains on 80% of data, tests on the remaining 20% the model never saw. Reports real directional accuracy (52.1% for AAPL, honest, not inflated), MAE vs naive baseline, and strategy Sharpe ratio.

Portfolio

Markowitz Portfolio Optimizer

10,000 random weight vectors sampled across 7 stocks. Max-Sharpe portfolio selected. Sharpe 2.32 vs 0.67 equal-weight (+247%). Interactive efficient frontier, hover any portfolio to see its risk/return tradeoff.

MLOps

Full Production Pipeline

Airflow schedules daily ingestion and weekly retraining. MLflow tracks every experiment. MinIO stores model artifacts. Prometheus scrapes API metrics. Grafana visualises request latency and error rates.

Engineering

Redis-Cached Serving Layer

Predictions cached 1h, backtest 24h, portfolio 1h, sentiment 30min. XGBoost trains once per hour per symbol, subsequent requests are instant. force_refresh=true bypasses cache for live re-runs.
